# Prolific Business & Consultant — HRMS

A role-based Human Resource Management System starter for Prolific Business & Consultant.

## Current build
- HR/Admin login
- Employee login
- Role-based navigation
- HR dashboard
- Employee dashboard
- Employee overview
- Responsive layout

## Demo credentials

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.
